# Ekopeak

Hemsidan är byggd för att följa WCAG 2.2 nivå AA.

- `images/` – bilder som används på hemsidan
- `references/` – designreferenser från Figma (PNG, ej publicerade)
- `css/`, `js/`, `index.html` – själva sajten

## Tabbordning

1. Hoppa till innehållet-länk (syns bara vid tabbning)
2. Header: logga, Tjänster, Kontakt, Boka en fri rådgivning, språkknapp (på mobil: logga, språkknapp, meny)
3. "Ekonomi och redovisning" + undertext
4. Knapparna "Våra tjänster" och "Kontakta oss"
5. Förtroendefältet (tre punkter)
6. "Allt inom ekonomi…" + ingress
7. Korten Bokföring, Lönehantering, Bokslut, Deklaration
8. "Så smidigt blir du kund hos oss" + ingress
9. Stegkorten 1–3
10. "Redo för en enklare ekonomivardag…" + text
11. Knapparna "Boka en fri rådgivning idag" och "Ring oss"
12. "Inga förpliktelser • 100% sekretess"
13. Footer: beskrivning och org.nr
14. Footer Kontakt: telefon, e-post, öppettider, stad
15. Footer Tjänster: länkarna

I Safari: slå på "Tryck på Tabb för att markera varje objekt på en webbsida" under Inställningar ▸ Avancerat, eller använd Alternativ + Tab.
